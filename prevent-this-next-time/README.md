# Prevent This Next Time

Set rules for Hermes connector writes in your Desktop or CLI thread on macOS/Linux, or your optional owner Telegram DM. Say “From now on, ask me before posting in #customer-updates” to review the exact request before it goes out, or “Never post in #customer-updates” to block it.

The plugin includes declarations for Slack posts, Discord messages, GitHub and Linear issues, Notion comments, and tasks in Asana, ClickUp, and Todoist. Custom HTTPS connectors can declare their own operations. Enforcement applies to declared writes. Use the dedicated profile to keep alternate write tools outside Hermes's tool inventory. Native chat control checks the authenticated OS owner before applying a rule or releasing a staged write.

Set up the profile and initialize its local policy database before use. [Setup, configuration, and disclosures](https://github.com/AceVikings/prevent-this-next-time#setup-on-hermes-v0231)
